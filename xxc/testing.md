# 客户端测试

## 启动测试模式

客户端调试模式可以启动为测试模式，在测试模式下可以进行自动化测试或者手动执行测试。要启动测试模式，需要设置环境变量 `TEST=1` 并执行 `npm run hot-server`：

```sh
TEST=1 npm run hot-server
```

## 定义测试

### 测试定义构成

每一个测试有如下部分组成：

* **名称**：测试的名称，例如 `'测试两个数相加'`；
* **分组**：测试的分组，要定义测试分组，可以在名称末尾通过 `@分组名称` 的形式定义，例如 `'测试两个数相加 @基础算法'`；
* **类型**：测试的类型包括 `单元测试`、`集成测试` 和 `系统测试`，默认情况下，测试均为单元测试，要定义一个集成测试，需要为测试名称或测试分组添加前缀 `* `，例如 `'* 测试一对一消息发送功能'`，如果要定义系统测试，需要为测试名称或测试分组添加前缀 `! `，例如 `'* 测试通讯录基本功能'`；
* **标签**：标签用于更灵活的定义测试属性，方便进行管理，可以在名称末尾通过 `#标签1 #标签2` 的形式定义，例如 `'测试两个数相加 #算法'`；
* **方法**：方法用于定义测试如何执行，通常在方法中判定一个或多个经过计算的值是否符合预期；
* **步骤**：在测试方法中，可以通过多个步骤来执行此次测试；
* **自动执行时机**：当一个测试可以被自动执行时，需要指定执行的时机，时机可以为其他测试执行完成后，或者系统中某个事件触发时进行，通过在用例或步骤名称中通过 `=事件名称)` 或 `=>用例或步骤名称)`。

为了便于管理，在喧喧客户端中测试的分组和标签已经预设了一些值，在定义测试时应该尽量使用这些预设的值。

#### 预设的测试分组

* `utils`：工具函数
* `exts`：扩展机制
* `ui`：界面交互
* `api`：接口
* `components`：组件
* `config`：系统配置
* `db`：数据库

#### 预设的测试标签

* 平台类型：
  * `platform/electron`：Electron 相关
  * `platform/browser`：浏览器相关
* 操作系统：
  * `os/mac`：macOS 相关
  * `os/win`：Windows 相关
  * `os/linux`：Linux 相关
* 模块：
  * `module/chats`：聊天
  * `module/members`：成员
  * `module/user`：当前用户
  * `module/screen-share`：屏幕共享/截屏
  * `module/commander`：命令系统
  * `module/contextmenu`：上下文菜单
  * `module/lang`：多语言
  * `module/updater`：自动更新
  * `module/events`：事件机制
* 其他：
  * `react`：React 相关
  * `perf`：性能测试相关

### 自动执行时机事件类型

* `login`：用户登录后；
* `logout`：用户登录出后；
* `sendMessage`：用户发送消息；
* `receiveMessage`：用户接收消息。

### 测试脚本

通过测试脚本来定义测试，测试脚本文件为一个 JavaScript 文件，可以在一个文件中定义多个测试。可以为客户端源代码目录（`xxc/app/`）中的每一个源文件定义一个测试脚本文件，文件名与源文件名称相同，但扩展名默认为 `.t.ts`。

在测试脚本中定义测试的方法与 [jest](https://jestjs.io/) 的方式基本相同，可以通过全局方法 `test(name, fn)` 来定义一个测试，通过全局方法 `expect(value)` 来判定值是否符合预期。例如：

```js
test('测试两个数相加 @基础算法 #加法', () => {
    expect(1 + 1).toBe(2);

    // 你可以调用多次 expect..toBe
    expect(1 + 2).toBe(3);
});
```

当一个测试中包含多个步骤时可以通过全局方法 `describe(name, fn)` 的形式来定义一个测试，然后在 `describe` 的回调方法中通过多次调用 `test` 来定义每一个测试步骤，例如：

```js
describe('基础算法测试 #加法', () => {
    test('测试 1 + 1', () => {
        expect(1 + 1).toBe(2);
    });

    test('测试 1 + 2', () => {
        expect(1 + 2).toBe(3);
    });
});
```

```sh
npm run package -- --test
```

npm run package -- -T
