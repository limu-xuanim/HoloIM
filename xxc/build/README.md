# 喧喧客户端打包

## 定制打包需要的信息和资源

* **应用名称**：例如 “喧喧”；
* **应用内部名称**：例如 “xuanxuan”，必须为英文字符串和 “-” 组成；
* **默认界面语言**：目前支持简体中文、繁体中文和英文，默认根据操作系统自动设置；
* **是否支持切换到其他语言**：可以选择不支持切换，界面上会不再显示语言切换按钮；
* **应用支持网址**：可以留空；
* **应用作者名称**：可以留空；
* **应用开发公司名称**：可以留空；
* **通知中心名称**：默认为“小喧喧”，如果需要定制则同时需要指定各个语言版本的名称；
* **应用 LOGO 资源文件**：推荐大小为 `700x260`，例如：
  ![logo.png](../app/media/img/logo.png)
* **应用图标资源文件**：推荐大小为 `1024x1024`，例如：
  ![logo.png](../resources/icons/1024x1024.png)
